PROJ_01

8-Bit Single-Cycle CPU

Verilog AMD Vivado FPGA RTL Design

Designed and verified a complete 8-bit single-cycle processor from scratch in Verilog. Features a custom 12-instruction ISA with R/I/J-type instruction encoding, complete datapath (ALU, 8-bit register file, decoder, instruction & data memory), and comprehensive testbench suite. All 4 benchmark test programs passed behavioral simulation and timing verification in AMD Vivado.

PROJ_02

Autonomous Drone System

ROS 2 Python PX4 Computer Vision

Developed an autonomous drone navigation system using ROS 2, Python, and PX4 flight controller integration. Implements autonomous waypoint trajectory following, real-time obstacle avoidance algorithms, and telemetry telemetry monitoring. Built with modular node architecture for camera sensor integration and mission control.
