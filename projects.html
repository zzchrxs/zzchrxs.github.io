8-Bit Single-Cycle CPU

Verilog AMD Vivado FPGA RTL Design

Designed and verified a complete 8-bit single-cycle processor from scratch. Features a custom 12-instruction ISA with R/I/J-type encoding, full datapath (ALU, register file, decoder, instruction/data memory), and comprehensive testbench suite. All 4 test programs pass behavioral simulation in AMD Vivado.

Autonomous Drone System

ROS 2 Python PX4 Computer Vision

Developed an autonomous drone navigation system using ROS 2 and PX4 flight controller. Implements waypoint navigation, obstacle avoidance, and real-time telemetry monitoring. Built with modular architecture for sensor integration and mission planning.
